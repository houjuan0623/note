# 待解决：为什么在Rocketchat中长短连接都emit('accounts.login')，进而生成了session文档？

在 Web 开发中，session 是一种在服务器端存储用户信息的机制，用于跟踪用户的整个会话过程。它通常用于：

* **用户身份验证**：例如，用户登录网站后，服务器会创建一个 session，并在其中存储用户的 ID、权限等信息。
* **购物车功能**：用户将商品添加到购物车时，服务器会将商品信息存储在用户的 session 中。
* **个性化推荐**：根据用户的浏览历史和偏好，推荐相关内容。

**使用方法**：

* **创建 session**：当用户首次访问网站时，服务器会创建一个新的 session，并为其分配一个唯一的 ID。
* **存储数据**：服务器可以使用 session ID 作为键，将用户信息存储在服务器端的内存、数据库或文件中。
* **读取数据**：当用户再次访问网站时，服务器会根据 session ID 检索对应的用户信息。
* **销毁 session**：当用户退出登录或 session 超时时，服务器会销毁该 session。

目前阅读代码看到的是长短连接登录成功后都会创建session，但是短连接中在触发accounts.login的同时触发了device.login。
