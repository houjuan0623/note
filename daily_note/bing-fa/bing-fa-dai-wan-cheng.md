# 并发-待完成

## 通讯并发

这种类型的并发开发者一般不考虑，因为服务器已经帮我们解决，比如nodejs http server，tomcat server等等。

稍后可以将共享服务器和专用服务器通过图示展示出来。

## 程序并发

要解决的问题：程序的执行前后要有逻辑关系。

### 进程并发

解决方案：通过共享内存，使用IPC通信即可解决。

### 线程并发

解决方案：通过堆数据结构即可解决。

## 数据库并发

要解决的问题：为了解决数据的正确性。为了保证数据的正确性，要考虑：完整性，一致性，并发性。
